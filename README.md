# Rifa María

Sitio web de rifas para la Tiendita María3y.

## Estado

Proyecto en etapa inicial: todavía no hay código de la aplicación.

## Alcance previsto

- Página de campaña con el premio y la selección de tickets.
- Formulario de compra con datos del participante y aceptación de bases.
- Pago en línea mediante pasarela.
- Recuperación de tickets por correo.
- Panel de administración para ventas, tickets y sorteo.
